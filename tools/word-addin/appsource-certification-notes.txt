OPENCASELAW WORD ADD-IN — CERTIFICATION TESTING GUIDE

1. OVERVIEW

OpenCaseLaw provides instant access to 1,050,000+ Swiss court decisions,
5,519 federal laws, and 26,000 cantonal legislative texts directly
inside Microsoft Word. Users can search, read, and insert correctly
formatted legal citations.

The add-in has two tiers:
- FREE (no account needed): search, citation insert, law lookup,
  language switching, full decision text
- PRO (CHF 5/month via Stripe, cancelable anytime): AI reference
  verification, AI-assisted argument search, document scan

The Pro subscription is clearly disclosed in:
- The manifest description (all 4 languages)
- The AppSource listing description
- The add-in settings panel
- The terms of use page

All court decision data is public domain (CC0 1.0). Swiss court
decisions are public records under Swiss law.

3. STEP-BY-STEP TESTING

--- Free features (no key needed) ---

Test 1: Search by case reference
  - Type "BGE 133 III 121" in the search bar, press Enter
  - Expected: Detail view with headnote (Regeste), considerations
    (Erwägungen), and full text
  - Click "Zitierung einfügen" (Insert citation)
  - Expected: "(BGE 133 III 121)" inserted at cursor in document

Test 2: Search by topic
  - Type "Mietrecht Kündigung" (tenancy law termination)
  - Expected: Ranked list of relevant decisions within 2-5 seconds

Test 3: Law article lookup
  - Type "Art. 41 OR" (Art. 41 of the Code of Obligations)
  - Expected: Card with full article text, paragraph numbers.
    Decision results appear below.

Test 4: Language switching
  - Click "FR" button at the top
  - Expected: All UI labels switch to French. Court names change
    (e.g., "Bundesgericht" → "Tribunal fédéral"). Citation format
    changes (BGE → ATF).
  - Also test "IT" (Italian) and "EN" (English)

Test 5: Citation insertion
  - Search any decision, open detail view
  - Click "Zitierung einfügen" button
  - Expected: Formatted citation inserted at cursor position
  - The citation format matches the selected language

--- Pro features (use test key above) ---

Test 6: Verify reference
  - Type a sentence in the Word document, e.g.:
    "Gemäss BGE 133 III 121 ist der Vermieter zur Kündigung berechtigt."
  - Select the sentence
  - Click "Prüfen PRO" (Verify reference) in the add-in panel
  - Expected: AI analysis showing whether BGE 133 III 121 actually
    supports the claim, with relevant consideration quoted

Test 7: Find supporting decision
  - Type a legal statement in the document, e.g.:
    "Der Mieter hat das Recht, Mängel der Mietsache zu rügen."
  - Select the statement
  - Click "Begründung PRO" (Find support)
  - Expected: AI searches for decisions that support or contradict
    the statement

Test 8: Document scan
  - With a document containing legal references open
  - Click "Scan PRO"
  - Expected: AI scans the document for legal references

4. EXTERNAL SERVICES

mcp.opencaselaw.ch (our API server)
  - Purpose: All search queries, decision retrieval, law lookup
  - Auth: None required for free features
  - Data: No user data stored, no cookies
  - Hosting: Hetzner, Germany
  - Protocol: HTTPS only

checkout.stripe.com / api.stripe.com
  - Purpose: Payment processing for Pro subscription (CHF 5/month)
  - Triggered: ONLY when user clicks "Upgrade to Pro" in settings
  - Data: Stripe handles all payment data; we never see card details
  - We store: Stripe customer ID and subscription ID only

api.anthropic.com
  - Purpose: AI inference for Pro features (verify, find-support, scan)
  - Triggered: ONLY when Pro subscriber explicitly clicks a Pro button
  - Data sent: Selected text from document + search context
  - No automatic transmission of document content

5. PERMISSIONS

ReadWriteDocument
  - Required to insert citations at cursor position
  - The add-in ONLY writes when user clicks "Insert citation"
  - The add-in ONLY reads selected text when user clicks a Pro
    feature button (verify/find-support/scan)
  - No background reading or writing of document content

6. PRIVACY

- No user accounts required for core functionality
- No cookies set
- No tracking pixels or analytics scripts
- No document content transmitted without explicit user action
- Pro requests are redacted client-side before transmission (js/redact.js, always on):
  e-mail, AHV, IBAN, UID, phone, date of birth, address, postal code/city, titled
  names -> placeholders; server re-checks the five structured patterns and rejects
  with 400 client_redaction_incomplete otherwise. Pattern-based; limits disclosed
  in the privacy policy.
- Search queries are not logged or associated with users
- Optional anonymous install-cohort signal (opt-out in settings)
- Privacy policy: https://word.opencaselaw.ch/privacy.html
- Full privacy policy: https://opencaselaw.ch/datenschutz/
- Terms of use: https://word.opencaselaw.ch/terms.html
