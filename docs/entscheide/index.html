Federal & Cantonal Legislation

via MCP

Fedlex SPARQL endpoint mirrored monthly and indexed in SQLite (FTS5): 5,516 federal laws, ~133,468 articles in DE/FR/IT, full amendment history. Cantonal legislation locally mirrored from LexFind (~30,000 acts, monthly refresh, live API as fallback). Article lookup in <1 ms.

Federal law (local) get_law("OR", article="41")
Cantonal (Portale + LexFind) search_legislation("Mietrecht", canton="ZH")
Recent amendments browse_legislation_changes(canton="CH")

What you can do after connecting:
  • Search decisions in natural language — by keyword, topic, statute, or legal concept
  • Look up any decision by docket number — with full text and metadata
  • Retrieve the current text of 5,516 federal laws (~133,468 articles, DE/FR/IT) — and search 15,722 cantonal enactments
  • View statistics and coverage across all federal and cantonal courts
  • Find leading cases for any law or legal area, ranked by citation count
  • Trace citation networks — see what a decision cites and what cites it
  • Analyze how jurisprudence on a topic has evolved year by year
  • Draft research memos from case facts — with relevant case law and statutes

Download

Download the full dataset as Parquet files

from datasets import load_dataset ds = load_dataset("voilaj/swiss-caselaw")

REST API

Query via HuggingFace Datasets Server API

GET /rows?dataset=voilaj/swiss-caselaw &config=default&split=train &offset=0&length=10
